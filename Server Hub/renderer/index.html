                AutoSave
                
          
                When the server starts a world, a copy of it is taken first. When the server stops, another copy goes next to it. Each session replaces both, so there's always one copy from before the last session and one from after. They're listed under Worlds, then Backups.
                
          
        
                

        
                
          
                
            
                GitHub Cloud
                
            Off
          
                
          
                Optional. Each world's AutoSave copies go to a private GitHub repo you choose, so another computer with Bedrock Hub can carry on where you stopped. Packs aren't uploaded. When a world is downloaded, its packs come from your Mod Library.
                
          
                
          
                
        
                

        
                
          
                
            
                Mod Library backup
                
            Off
          
                
          
                Back up the extracted Mod Library to a separate private GitHub repo. Sync now uploads the latest library; Restore from GitHub replaces the local library and keeps the previous folder as a safety backup.
                
          
                
          
                
        
                

        
                
          
                
            
                Settings and sign-in backup
                
            Off
          
                
          
                Use a separate private GitHub repo to transfer app and server settings between devices. The backup is encrypted with your passphrase; Windows protects it on this device. Sign in to GitHub on each new device first.
