BABS: Bridged Android Bedrock Server

Host a Minecraft Bedrock Dedicated Server and the Bedrock Console Bridge from an Android phone or tablet. Friends on Xbox, PlayStation and Switch can join from their Friends list.

Built for hosting

  • Start, stop and restart the Bedrock server and Console Bridge.
  • See server and bridge status, and use the live console.
  • Bring in worlds and add packs to the world the server runs.
  • Import and export Bedrock worlds.
  • Keep the server and bridge running with an Android foreground service.

How it fits with Bedrock Hub

Bedrock Hub is the all-in-one Windows app for add-ons, worlds and server hosting. BABS focuses on hosting from Android; the apps are separate and have their own features.

Unlike Bedrock Hub, BABS doesn't include a mod library. Instead, bring pack files directly into the world its server runs.

Before hosting

Device and network notes

Android device

  • Android 10 or later; designed for phones and tablets.
  • A recent flagship device and 8 GB or more of RAM are recommended for the emulated server.
  • Allow roughly 1 GB of storage for the Linux environment and server, plus room for worlds and updates.
  • Android battery optimization can interrupt hosting, so sustained background use may need device settings adjusted.

Network and performance

  • The Bedrock server is an x86_64 program; on ARM phones, BABS runs it through box64 emulation, which can be slower than a desktop.
  • For friends outside your home network, the server needs a reachable public address and UDP ports forwarded on your router.
  • Mobile networks using carrier-grade NAT generally won't accept the inbound connections the server needs. Wi-Fi is the practical setup.
  • The server is downloaded to the device after accepting Minecraft's EULA; it isn't bundled with BABS.
Development status. BABS is still being developed. The current build has been checked on an x86_64 Android emulator; real ARM-device performance and console-player connections still need validation. This site does not yet provide a BABS download.
